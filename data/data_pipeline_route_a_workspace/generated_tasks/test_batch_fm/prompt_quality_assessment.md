# Route A 任务生成器 - Prompt 质量评估
**评估日期**: 2026-08-18
**批次规模**: 5 个 FM 任务, 5 个 Viz 任务
**生成成功率**: FM 100% (5/5), Viz 60% (3/5)

---

## 摘要

Route A 基于 LLM 的任务生成器在 FM（公式建模）任务上展现出**较强的 prompt 质量**，具备清晰的领域背景、贴近真实场景的设定，以及结构完整的技术要求。5 个 FM 任务全部成功生成,指令连贯,适合用于 Excel 自动化基准测试。Viz 任务在概念设计上表现良好,但存在技术生成问题（MergedCell 处理），导致 40% 的失败率。

**建议**: Route A 生成器**已具备生产可用性**,可用于 FM 任务生成。Viz 生成需要先修复输入工作簿操作代码,再考虑规模化。

## 4. 技术生成问题

### Viz 生成失败（2/5 失败）
**错误**：`AttributeError: 'MergedCell' object attribute 'value' is read-only` 以及取消合并单元格时出现的 `KeyError`

**根本原因**：生成的输入工作簿创建 Python 代码尝试：
1. 直接为合并单元格赋值（openpyxl 中此操作只读）
2. 对不存在或已经取消合并的区域执行取消合并操作

**影响**：
- viz_20260818_002（公寓社区租金与出租率周报可视化）— 在输入生成阶段失败
- viz_20260818_005（美国各州劳动力市场分析仪表板）— 在取消合并时出现 KeyError

**所需修复**：更新输入工作簿生成的 prompt，要求：
- 在清除公式/图表前先取消合并单元格
- 使用正确的 openpyxl 合并处理方式（取消合并 → 仅修改左上角单元格）
- 对已经取消合并的区域增加错误处理
